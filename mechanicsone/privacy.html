Privacy Policy

Beam & Stress — MechanicsOne. Last updated 30 August 2026.

This application collects no data of any kind.

It makes no network request, has no account, and sends nothing anywhere. There is no analytics, no crash reporting, no advertising identifier, and no third-party software development kit in it.

What that means precisely

  • No data is collected — not linked to you, not unlinked from you, not for any purpose.
  • No tracking, as App Store Connect defines the term. There are no tracking domains because there are no domains.
  • Nothing leaves your device. Everything you enter stays in the application's own storage on the device you entered it on.
  • No connection is needed to install, open, or use any part of the application.

How you can check this

The application ships with the App Sandbox enabled and requests only these entitlements:

  • com.apple.security.app-sandbox
  • com.apple.security.files.user-selected.read-write

Network client and network server entitlements are absent. A sandboxed application without them cannot open a network connection, whatever its code might attempt.

Children

The application collects nothing from anyone, of any age.

Changes

If this ever changes, this page will change before the version that changes it is submitted, and the change will be described here rather than replaced silently.
