Sample data for PlotOne

Four small files, one for each kind of data PlotOne draws. Download one, then in the app choose File > Import Data (⌘I on Mac) or Import Data at the top right on iPad, and pick it. The import sheet shows the parsed columns before anything is imported.

The first two import with the settings the sheet opens on. The other two are there to exercise the other plot kinds, so set Kind of data to the value in the last column first.

FileWhat it isKind of data
line_measured_vs_theory.csv A damped sine sampled 60 times: column 1 is X, then a measured curve and a theoretical one. Vectors · line plot (the default)
line_with_errors.csv A pressure decay with a per-point uncertainty: X, Y, ΔY. Turn on the error-column layout to draw the error bars. Vectors · line plot (the default)
matrix_field.csv A 40 × 60 grid of numbers with no header row — one scalar value per cell, drawn as a colour map. Matrix · field
bars_by_category.csv Five named cases with two values each. The first column is text, so this one is a bar chart rather than a line plot. Categories · bar chart

Any CSV, tab- or space-separated text file, or Excel workbook (.xlsx) of your own works too. Nothing is uploaded anywhere: the file is read on your device and stays there.
