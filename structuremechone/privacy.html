Privacy

This app collects nothing. There is no network code in it.

Data collected

None. Not analytics, not crash reports, not usage counts, not an identifier of any kind. The app has no account system and no server to talk to.

Data leaving your device

None. Everything you type stays on the device you typed it on. The shipped binary contains no networking symbols at all, which is checked mechanically before every release.

Third parties

There are none. The app links only against Apple's own system frameworks.

Children

Since nothing is collected, nothing is collected from anyone of any age.
